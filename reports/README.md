# Reviewed reference outputs

Generated by `python examples/reproduce.py --output outputs/case-study-final`
with 200 bootstrap refits, seed 2026, and the declared silicon configuration.
The repository stores compact summaries. Full per-channel and bootstrap tables
are reproduced into the requested output directory, not duplicated here.

- `measured_report.json`: one **experimental** spectrum and **model-derived** fit,
  audit, source metadata, all conditional five-channel-block intervals and flags.
- `independent_bootstrap.json`: independent-residual intervals for the same fit.
- `model_comparison.csv`: equal-window AICc comparisons; residual correlation limits
  the independent-noise interpretation of this ranking.
- `sensitivity.csv`: declared window/background/line-shape estimates; not a probability interval.
- `synthetic_batch.csv`: three **synthetic** files, generating truth and default
  fit/QC results. The spike is deliberately retained and flagged.
- `validation.json`: 100-trial **synthetic validation**, including numerical bias,
  RMSE and local-covariance coverage. Not experimental accuracy.

Peak centres, widths, gamma and sigma are in cm^-1; height/background/residuals
are in source intensity units; area is intensity × cm^-1. AICc, correlations and
SNR are dimensionless. Read `docs/VALIDATION.md` before interpreting these tables.
